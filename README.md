# Login Form Project

A simple login form built with HTML, CSS, and JavaScript. Created as a group activity to practice Git and GitHub collaboration (branching, commits, and merging).

## Description

This project demonstrates a basic login form with username and password fields, responsive styling, and client-side validation that shows an error when a field is left empty.

## Usage

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Open `index.html` in any modern web browser.
3. Enter a username and password, then click **Login**.
4. If either field is empty, an error message is shown; otherwise a success message appears.

## Files

- `index.html` - Form structure (HTML)
- `style.css` - Styling (CSS)
- `script.js` - Validation logic (JavaScript)
- `README.md` - Documentation

## Team Workflow

Each member worked on a dedicated branch and merged into `main`:

- `html-form` - Built the form structure
- `css-styling` - Added styles
- `js-validation` - Added empty-field validation
- `docs` - Wrote usage instructions and project description
